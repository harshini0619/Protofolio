# Harshini's Portfolio

A responsive dark-themed personal portfolio built with HTML, CSS and vanilla JavaScript.

## Run locally
1. Extract the ZIP file.
2. Open `index.html` in a browser.

## Personalize before publishing
Open `index.html` and replace:
- `YOUR_EMAIL@example.com` with your professional email address.
- `YOUR_LINKEDIN_URL` with your LinkedIn profile URL.

Review project and certification descriptions. Add repository/demo links and certificate verification links where available. Update education details if your graduation status or details have changed.

## Publish free with GitHub Pages
1. Create a GitHub repository named `harshini0619.github.io`.
2. Upload `index.html`, `style.css`, `script.js` and this README to the repository root.
3. Open repository Settings → Pages.
4. Select deploy from the `main` branch and `/ (root)`, then Save.
5. Your site will be available at `https://harshini0619.github.io` after GitHub Pages finishes publishing.

This site uses Google Fonts over the internet; it falls back to system fonts if they are unavailable.
